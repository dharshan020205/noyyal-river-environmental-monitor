# Project scope and claims

## Accurate project description
**Noyyal River Environmental Monitor: Evidence-Based Water-Quality Analysis and Pollution-Abatement Decision Support**

## Implemented
- CSV ingestion and validation.
- Numeric conversion and basic data cleaning.
- Descriptive TDS summary metrics.
- Location/period/parameter filters.
- Downloadable filtered CSV.
- Upstream/downstream comparison of reported 2014–15 values.
- Transparent relative-comparison screening messages.
- Evidence-linked pollution-abatement recommendations.
- Methodology, sources and limitations.

## Not implemented
- No trained ML model.
- No future water-quality prediction.
- No real-time sensor/IoT feed.
- No live connection to TNPCB or CPCB databases.
- No automated regulatory compliance certification.
- No causal source attribution.

## Why this wording matters
A project presentation should distinguish implemented features from proposed future work. Do not claim "AI prediction", "real-time monitoring", "automatic pollution detection" or "regulatory compliance" unless those capabilities are actually implemented and validated.
